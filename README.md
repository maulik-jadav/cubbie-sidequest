# SideQuest for Cubbie

“I have 70 minutes between classes. Now what?”

SideQuest finds one verified nearby activity that fits your class schedule, budget, and preferences, then offers a reminder to leave in time for class.

## Install

Text Cubbie this link:

https://github.com/maulik-jadav/cubbie-sidequest/tree/main/sidequest

Approve the install when Cubbie asks. Send your request as a new message after installation. Text the same folder link again after an update to fetch the latest version.

## Try it

Text: “I'm bored and broke.” Then provide your current campus/building and a real next class time and building when asked. SideQuest can use connected Google Calendar; you can also supply the schedule yourself. “Broke” means free options. Accept the suggested plan and leave-by reminder if you want the alert.

Expect one activity, verified cost and current hours/event details, a source link, estimated travel for both legs, and a leave-by time with a 5-minute arrival buffer. If nothing fits or can be verified, expect an honest fallback rather than an invented event.

## Requirements

Runs using Cubbie's web/browser abilities, memory, and reminders. Google Calendar is optional. No scripts, package installs, API keys, or team backend. Calendar and reminder behavior must be tested on your own Cubbie. Recurring gap check-ins require explicit opt-in; location is supplied by you, not automatically tracked.

## Privacy and actions

Uses public place names for lookups rather than sharing your full schedule. Bookings and other external actions require your approval; payments are handed back to you. See [the Skill](sidequest/SKILL.md) for the full workflow.
